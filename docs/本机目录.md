# GriddyTranslate 固定工作目录

今后的源码修改、验证和打包都在 **D:\Documents\GriddyTranslate** 进行。

- `src/`：Godot 源码、原版资源、测试和使用说明。
- `dist/GriddyTranslate/`：可直接运行的 Windows 便携版。双击 `GriddyTranslate.exe`。
- `packages/GriddyTranslate-Windows.zip`：发给别人使用的完整压缩包；解压整个文件夹后即可启动。
- `tools/`：本机开发使用的 Godot、导出模板、独立启动器源码。
- `qa/`：测试日志、截图、临时解压验证和先前版本备份。
- `build.ps1`：从这个固定目录构建、验证并生成 ZIP，不依赖原 Codex 会话目录。

用户设置保存在 `%APPDATA%\Godot\app_userdata\GriddyTranslate\translator.cfg`，与 GriddyCode 分开。原文和译文仅保存在运行时内存中。

详见 `src/使用说明.md` 和 `docs/修复说明.md`。
