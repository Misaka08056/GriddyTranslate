# GriddyTranslate 使用说明

从桌面 **GriddyTranslate** 快捷方式启动。便携版请先解压整个 `GriddyTranslate-Windows.zip`，再双击文件夹里的 **GriddyTranslate.exe**。主界面就是 GriddyCode 原版的文字画布：直接输入或粘贴文本，按 **Ctrl + Enter** 翻译，译文会显示在同一个画布。

## 最常用的操作

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + Enter | 翻译；网络失败后重试 |
| Ctrl + Tab | 在原文和译文之间切换 |
| Esc | 收起当前面板；没有面板时返回原文 |
| Ctrl + Shift + C | 复制译文 |
| Ctrl + Shift + X | 把译文作为新原文，并交换语言方向 |
| Ctrl + N | 清空当前文本 |
| Ctrl + , | 打开或收起原版设置面板 |
| Ctrl + T | 打开或收起原版主题选择 |
| Ctrl + O / Ctrl + L | 选择翻译语言 |
| Ctrl + I | 打开帮助 |
| F11 | 全屏 / 窗口切换 |
| Ctrl + 加号 / 减号 | 放大 / 缩小 |
| Ctrl + 0 | 恢复 100% 缩放 |

输入时，原版镜头会跟随光标，并按文本长度放大或缩小。译文为只读；想修改文本时先按 Ctrl + Tab 返回原文。复制译文可以直接用 Ctrl + Shift + C。

## 有道与 MyMemory

按 **Ctrl + ,**，找到 **Translation Source / 翻译来源** 下拉框：

- **有道 / 免密钥体验**：默认来源，使用有道官方公开体验接口，无需填写密钥。
- **MyMemory / 免密钥**：另一项免费在线来源，有每日免费额度。

选好后再次按 Ctrl + , 收起设置，再按 Ctrl + Enter 翻译。两个来源分别缓存译文；选了某个来源后，软件不会在出错时偷偷换成另一项。有道体验接口的限额或可用性可能调整，遇到错误可以稍后重试或手动切换来源。

## 例句与乱码动画

在设置里使用 **Show Examples / 显示例句** 开关，默认开启。

英译中完成后，软件会在画面下方显示一条英文例句和中文译文：先逐字出现乱码，再从左到右逐字恢复为例句。例句没有边框、按钮或常驻面板。关闭开关后会隐藏例句，并停止发起新的例句查询。

输入单词时查询该词；输入短语时查询**完整短语**，只显示包含完整短语的例句，绝不会从中挑一个单词替代。长句、段落和没有对应完整词典词条的输入不显示例句。有道返回普通句子的搜索结果也不会被当成短语词条。例句查询仅接受不含句子标点、最多 100 个字符及 12 个单词的英文词或短语；主翻译仍支持原有 5000 字限制。

有道模式优先使用有道词典的双语例句；无双语例句时尝试 Free Dictionary / Wiktionary 的**同一个完整词条**，再由有道翻译。MyMemory 模式查询 Free Dictionary / Wiktionary，再交给 MyMemory 翻译。没有完整词条的合适例句时，只显示主译文。例句跟随正文镜头，乱码动画使用固定字位，避免换行和位置抖动。

## 语言与外观

按 Ctrl + O 或 Ctrl + L。用上下方向键选择源语言，按 Enter；再选择目标语言，再按 Enter 确认。Esc 会取消未确认的选择。默认 Smart 自动识别中英文，也能识别日文、韩文和俄文；其他语言建议手动选择。

语言列表现在按完整内容居中，镜头根据屏幕大小适配，底部语言与键盘提示均可见。窗口大小改变或切换全屏时会重新适配。最小缩放时背景也始终覆盖屏幕，不再露出顶部灰色空白。

设置里的 **Glow** 控制原版泛光，**Sunlight** 与 **VHS and CRT** 一次开启一种。VHS/CRT 的过曝和屏幕坐标问题已修正，呈现扫描线、彩色错位与电视暗角。**Editor Font** 的 GriddyCode Default 对应原版初始画布字体，Fira Code 使用原版 MSDF 导入参数。中文、emoji 与设置图标已补齐字体支持。

右侧跳跃猫动画已按要求移除。设置里另有 **屏幕晃动** 开关、**设置动画速度** 拖动条（25%–300%）、**缩放比例** 拖动条（50%–200%）、**全屏** 开关。100% 动画速度为原版默认，越大越快。关闭屏幕晃动会停止周期性浮动与音乐脉冲，仍保留输入聚焦。

**译文位置** 下拉框可以选择“替换原文”或“保留原文 · 下一行译文”。后一种会同时显示原文与译文，Ctrl + Shift + C 仍只复制译文；要修改原文，按 Ctrl + Tab。

**Blink Interval / 闪烁间隔** 是输入光标多久切换一次显示/隐藏，单位为秒。0.6 表示亮 0.6 秒、灭 0.6 秒，完整周期约 1.2 秒。**Caret Blink / 光标闪烁** 是开关，与间隔分开。

## 自动翻译、保存与网络

Auto Translation 默认关闭，开启后停止输入约 1.2 秒会自动翻译。主翻译单次最多 5000 个字符；较长文本会分段请求。网络错误不会清掉原文，重试用 Ctrl + Enter。

原文、译文和例句仅放在内存中，关闭软件后不会保存；翻译来源、语言、主题、字体与开关会自动保存。翻译时文本会发送给你选中的在线服务；显示例句时还会查询相应词典。

**GriddyTranslate.exe** 现在是独立原生启动入口，会只在自身及翻译器进程内禁用已知冲突的 RTSS Vulkan 图层。保持 `GriddyTranslate.runtime.exe`、`GriddyTranslate.runtime.pck` 和 Lua DLL 与它同目录；不要只复制入口 exe。它可以与 GriddyCode 独立启动，设置保存在各自的用户目录。

今后的开发目录为 `D:\Documents\GriddyTranslate\src`，运行目录为 `D:\Documents\GriddyTranslate\dist\GriddyTranslate`，分享 ZIP 位于 `D:\Documents\GriddyTranslate\packages`。需要 Windows 10/11 64 位、支持 Vulkan 的显卡及网络。
