# GriddyTranslate 使用说明

从桌面 **GriddyTranslate** 快捷方式启动。便携版请先解压整个 `GriddyTranslate-Windows.zip`，再双击文件夹里的 **GriddyTranslate.exe**。主界面就是 GriddyCode 原版的文字画布：直接输入或粘贴文本，按 **Ctrl + Enter** 翻译，译文会显示在同一个画布。

## 最常用的操作

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + Enter | 翻译；网络失败后重试 |
| Ctrl + Tab | 在原文和译文之间切换 |
| Esc | 收起当前面板；没有面板时返回原文 |
| Ctrl + Shift + C | 复制译文 |
| Ctrl + Shift + X | 把译文作为新原文，并交换语言方向 |
| Ctrl + N | 清空当前文本 |
| Ctrl + , | 打开或收起原版设置面板 |
| Ctrl + T | 打开或收起原版主题选择 |
| Ctrl + P | 播放原文读音 |
| Ctrl + O | 播放译文读音 |
| Ctrl + D | 收藏选中的单词 / 完整短语，没有选区则收藏完整输入 |
| Ctrl + B | 打开或收起单词本 |
| Ctrl + Shift + O | 在 Obsidian 打开单词本中选中的词条 |
| Ctrl + L | 选择翻译语言 |
| Ctrl + I | 打开帮助 |
| F11 | 全屏 / 窗口切换 |
| Ctrl + 加号 / 减号 | 放大 / 缩小 |
| Ctrl + 0 | 恢复 100% 缩放 |

输入时，原版镜头会跟随光标，并按文本长度放大或缩小。译文为只读；想修改文本时先按 Ctrl + Tab 返回原文。复制译文可以直接用 Ctrl + Shift + C。

## 开屏与自动换行

启动首页名称为 **cybertranslator**。开屏参考所提供视频的完整约 **11 秒**节奏，使用红黑视频背景、锐角黄色字标和青色故障闪动。双击 **GriddyTranslate.exe** 时，原生启动器先播放开屏，Godot 引擎与编辑器在它后方加载，因此动画可以覆盖引擎启动的空白时期。

**完整 logo 显示至少半秒，且编辑器绘制完成后，任意按键或点击才可跳过**；之前的输入会被忽略，不会自动排队跳过。跳过和正常结束都会播放约 **0.45 秒退场动画**，退场中连按也不会截断。按 **Ctrl + ,**，关闭 **开屏动画 / Startup Animation** 后，下次启动直接进入文字画布，且不会加载开屏资源。请从 **GriddyTranslate.exe** 启动；直接运行 runtime.exe 时，备用开屏仍需等待引擎初始化。

**自动换行 / Auto Wrap** 默认开启，原文与译文都会在设定宽度内换行。设置里的 **每行长度 / Wrap Length** 可在 **10–120 字符宽**之间调节，默认 **40**。这个数值以英文等宽字符的宽度为基准，中文通常约占两个字符宽，英文优先在单词之间换行。

这是显示用的软换行：复制、翻译、例句查询和撤销时保留你输入的原始文本，Enter 仍用于添加真实段落。关闭自动换行即可恢复单行显示。

## 单词本

在原文里选中一个单词或完整短语，按 **Ctrl + D** 收藏。没有选区时使用完整输入；长句需要先选词，不会被自动拆成多个词。收藏优先复用已有译文和例句，必要时只翻译选中的内容；相同词与语言方向会合并收藏，保留你写的笔记。英语词条可在后台补充有道词典音标与真实双语例句，未收录时保留已有释义。

按 **Ctrl + B** 呼出单词本。它沿用文字画布的字体、泛光、滑入动画和镜头聚焦，不增加常驻工具栏。直接输入可搜索原词、译文、标签和笔记。

| 单词本内快捷键 | 操作 |
| --- | --- |
| ↑ / ↓、PgUp / PgDn | 选择词条 / 翻页 |
| Enter | 展开或收起词条详情 |
| Ctrl + F | 返回搜索框并选中搜索文字 |
| Ctrl + E | 编辑译文、标签和本地笔记 |
| Tab / Shift + Tab | 编辑时切换字段 |
| Ctrl + Enter | 保存编辑 |
| Ctrl + P / Ctrl + O | 播放当前词条的原词 / 译文读音 |
| Ctrl + Shift + O | 打开该词条对应的 Obsidian 笔记 |
| Delete | 请求删除；5 秒内再次按 Delete 确认 |
| Esc | 取消编辑或删除确认、清除搜索、收起详情，再收起面板 |

标签用逗号分隔。开启 Obsidian 自动同步后，删除词条也会将其对应笔记移到系统回收站，整篇笔记及手写内容可在那里恢复。关闭自动同步或暂时无法访问库时，删除记录会保存在本地，重启后仍可通过开启同步或“立即同步”重试；库内改名或移动过的笔记仍按固定 ID 定位。不会删除普通笔记或管理标记损坏的文件。

## 与 Obsidian 联动

按 **Ctrl + ,**，设置中提供 **Obsidian 自动同步**、**Obsidian 保管库**、**单词本同步文件夹** 和 **Obsidian 立即同步**。自动同步默认开启；关闭后仍可正常使用本地单词本。执行立即同步前需开启该开关。

尚未设置保管库时，软件读取 Obsidian 已注册的库列表，优先选择当前打开的库；只注册一个库时使用该库。多个库且没有正在打开的库时，请手动选择含 `.obsidian` 文件夹的保管库根目录。已保存的选择不会被自动切换。

你这台电脑当前识别的库是 iCloud 中的 **Eng**：`D:\Documents\iCloudDrive\iCloud~md~obsidian\Eng`。默认同步文件夹是 `GriddyTranslate/单词本`，因此笔记写在该库下面的同名子目录；这个路径来自本机 Obsidian 配置，程序没有写死开发电脑路径。可以在设置中改选其他库或库内相对文件夹。

每个词条是一篇 Markdown，包含语言、来源、收藏时间、标签、释义、可用音标和例句。同步与查找笔记在后台执行，完成或失败会显示通知；iCloud 将本地文件同步到其他设备的时间由 iCloud 客户端决定。用 **Ctrl + Shift + O** 打开笔记需已安装 Obsidian，且词条已成功同步。

笔记中的“释义”“例句”和“单词本笔记”由软件更新；末尾 **“我的笔记”** 留给你在 Obsidian 中补充，更新时会保留。用户自定义标题、软件管理区域以外的文字、未知 frontmatter 字段以及 Obsidian 的 `tags` 都会保留。单词本内修改的标签记录在 `griddytranslate_tags` 属性中。保留管理标记与固定词条 ID；在配置的同步文件夹及其子文件夹内改名或移动笔记后，软件仍能找到它。

当前联动将本地单词本更新写入 Markdown；在 Obsidian 的“我的笔记”中增加内容会保留在该文件里，不会导回本地单词本。同步遇到同名普通文件、相同 ID 的多个副本、损坏的管理标记或同时编辑冲突时会停止并保留原文件；处理提示后可再次执行立即同步。文件夹路径不能越出保管库，iCloud 占位文件可用，重定向链接不作为同步目标。

## 单词本保存与恢复

主动收藏的词条自动保存到 `%APPDATA%\Godot\app_userdata\GriddyTranslate\wordbook.json`，保存时保留上一版 `.bak`；中断保存或备份更新受阻时可能留下 `.rollback` 恢复文件。主文件缺失时先验证恢复副本，完整有效才加载并提示。主文件损坏时停止改写，保护原文件；请关闭软件、另存损坏文件，再检查和恢复备份。

便携包可解压后直接运行，个人单词本与偏好仍存放在 Windows 用户目录，不在 ZIP 内。换电脑时，在两边软件都关闭的情况下迁移该用户目录中的单词本及恢复文件；保管库路径需在新电脑重新选择。普通画布原文、译文和例句仍只在内存中，只有按 Ctrl + D 收藏的内容会保存。

## 播放读音

**Ctrl + P** 播放完整原文，按原文语言发音；**Ctrl + O** 播放完整译文，按生成该译文时的目标语言发音。无论画布当前显示原文、译文或“原文 + 下一行译文”，两个快捷键都读取对应文本，不会把合并显示的两段混在一起。语言选择使用 **Ctrl + L**。

读音使用有道在线语音，需要联网；句子在有道翻译刚完成时会复用返回的对应读音地址，直接下载音频。单词优先使用更快的词典录音，句子直接请求语音；长文本按需分段顺序播放。已播放过的相同文本与语言会复用内存中的音频，再次播放无需重复联网。再次按读音快捷键会停止旧播放并切换到新的读音，修改原文也会停止旧读音。没有译文时 Ctrl + O 会提示先翻译；服务不支持某种语言或网络失败时会显示错误，文本不会被清空。

## 有道与 MyMemory

按 **Ctrl + ,**，找到 **Translation Source / 翻译来源** 下拉框：

- **有道 / 免密钥体验**：默认来源，使用有道官方公开体验接口，无需填写密钥。
- **MyMemory / 免密钥**：另一项免费在线来源，有每日免费额度。

选好后再次按 Ctrl + , 收起设置，再按 Ctrl + Enter 翻译。两个来源分别缓存译文；选了某个来源后，软件不会在出错时偷偷换成另一项。有道体验接口的限额或可用性可能调整，遇到错误可以稍后重试或手动切换来源。

## 例句与乱码动画

在设置里使用 **Show Examples / 显示例句** 开关，默认开启。

英译中完成后，软件会在画面下方显示一条英文例句和中文译文：先逐字出现乱码，再从左到右逐字恢复为例句。例句没有边框、按钮或常驻面板。关闭开关后会隐藏例句，并停止发起新的例句查询。

输入单词时查询该词；输入短语时查询**完整短语**，只显示包含完整短语的例句，绝不会从中挑一个单词替代。长句、段落和没有对应完整词典词条的输入不显示例句。有道返回普通句子的搜索结果也不会被当成短语词条。例句查询仅接受不含句子标点、最多 100 个字符及 12 个单词的英文词或短语；主翻译仍支持原有 5000 字限制。

有道模式优先使用有道词典的双语例句；无双语例句时尝试 Free Dictionary / Wiktionary 的**同一个完整词条**，再由有道翻译。MyMemory 模式查询 Free Dictionary / Wiktionary，再交给 MyMemory 翻译。没有完整词条的合适例句时，只显示主译文。例句跟随正文镜头，乱码动画使用固定字位，避免换行和位置抖动。

## 语言与外观

左上角通知使用无外框的直角卡片与左侧色条，色条、文字和背景随当前主题变化。通知从左侧滑入并淡入，停留约 5 秒后滑出淡出；新消息会平滑替换旧消息，长通知自动换行并增高。通知在显示与动画期间均不拦截点击。

按 Ctrl + L。用上下方向键选择源语言，按 Enter；再选择目标语言，再按 Enter 确认。Esc 会取消未确认的选择。默认 Smart 自动识别中英文，也能识别日文、韩文和俄文；其他语言建议手动选择。

语言列表现在按完整内容居中，镜头根据屏幕大小适配，底部语言与键盘提示均可见。窗口大小改变或切换全屏时会重新适配。最小缩放时背景也始终覆盖屏幕，不再露出顶部灰色空白。

设置里的 **Glow** 控制原版泛光，**Sunlight** 与 **VHS and CRT** 一次开启一种。VHS/CRT 的过曝和屏幕坐标问题已修正，呈现扫描线、彩色错位与电视暗角。**Editor Font** 的 GriddyCode Default 对应原版初始画布字体，Fira Code 使用原版 MSDF 导入参数。中文、emoji 与设置图标已补齐字体支持。

主题、字体、翻译来源、译文位置等下拉选项使用新的选择菜单：背景与文字跟随主题，展开时对齐按钮，长列表可滚动，并自动避开窗口边缘。菜单与对应按钮在同一帧一起浮动，保持相对间隔；字体大小与列表高度不会随浮动变化。Ctrl+T 的主题按钮在输入区左侧，窗口缩放时菜单重新对齐。上下方向键切换，Enter 确认，Esc 先收起菜单；再次 Esc 才关闭所在面板。原版灰色菜单及截图已保留在源码 `Original/SelectionMenuBeforeRedesign` 中作为对照。

主题预览复用现有控件和字体，隐藏的设置与单词本在打开时更新配色，避免反复重建造成掉帧。选中文本沿用主题文字色；当前行、选择和重复单词高亮叠加时会自动保护文字对比度，避免 Rose Pine 等主题中出现整块浅色遮住文字。

右侧跳跃猫动画已按要求移除。设置里另有 **屏幕晃动** 开关、**设置动画速度** 拖动条（25%–300%）、**缩放比例** 拖动条（50%–200%）、**全屏** 开关。100% 动画速度为原版默认，越大越快。关闭屏幕晃动会停止周期性浮动与音乐脉冲，仍保留输入聚焦。

拖动设置滑块时，只有该滑块及其数值保持按下瞬间的屏幕位置和大小，其他设置文字、控件与镜头继续原有动画。松手后滑块平滑回到本行，不会改变“屏幕晃动”的偏好。滑入尚未完成时轨道暂不接收拖动，避免移动中的控件影响数值。轨道已加长；点选滑块后可以用左右方向键逐步细调，整数设置每次 1，闪烁间隔每次 0.1 秒。Esc 关闭面板时也会解除临时稳定状态。

**译文位置** 下拉框可以选择“替换原文”或“保留原文 · 下一行译文”。后一种会同时显示原文与译文，Ctrl + Shift + C 仍只复制译文；要修改原文，按 Ctrl + Tab。

**Blink Interval / 闪烁间隔** 是输入光标多久切换一次显示/隐藏，单位为秒。0.6 表示亮 0.6 秒、灭 0.6 秒，完整周期约 1.2 秒。**Caret Blink / 光标闪烁** 是开关，与间隔分开。

## 自动翻译、保存与网络

Auto Translation 默认关闭，开启后停止输入约 0.5 秒会自动翻译。Ctrl + Enter 立即请求；重复按同一文本的翻译快捷键不会重新发起正在进行的请求。修改原文或切换来源、语言后会取消旧请求，新翻译无需等旧请求结束。主翻译单次最多 5000 个字符；有道按最多 1000 个 UTF-16 单位分段，MyMemory 按最多 450 个 UTF-8 字节分段，较长文本最多同时请求两段，再按原顺序合并。网络错误不会清掉原文，重试用 Ctrl + Enter。

画布中的原文、译文和例句仅放在内存中，关闭软件后不会保存；主动收藏的词条保存在本地单词本，翻译来源、语言、主题、字体与开关会自动保存。翻译与收藏所需的译文请求会发送给你选中的在线服务；显示例句或补充收藏的音标、例句时还会查询相应词典。按读音快捷键会将对应文本发送给有道语音服务，音频缓存仅放在内存中。Obsidian 同步直接写入选定的本地库，跨设备同步交给 iCloud。

**GriddyTranslate.exe** 是独立原生启动入口，会先显示开屏，并只在自身及翻译器进程内禁用已知冲突的 RTSS Vulkan 图层。保持 `GriddyTranslate.runtime.exe`、`GriddyTranslate.runtime.pck`、`native-startup.frames` 和 Lua DLL 与它同目录；不要只复制入口 exe。它可以与 GriddyCode 独立启动，设置保存在各自的用户目录。

今后的开发目录为 `D:\Documents\GriddyTranslate\src`，运行目录为 `D:\Documents\GriddyTranslate\dist\GriddyTranslate`，分享 ZIP 位于 `D:\Documents\GriddyTranslate\packages`。需要 Windows 10/11 64 位、支持 Vulkan 的显卡及网络。
